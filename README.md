## About me

I build web applications and machine learning systems, working across data processing, model development, backend APIs and user interfaces. My projects include document-based AI assistants, rental verification workflows and image classification applications.

I’m pursuing a **Master’s in Applied Computer Science** at Hochschule Schmalkalden, following a B.Tech. in Computer Science and Engineering with a specialization in AI and ML. During two research internships at **NIT Warangal**, I worked on large language model development and text analysis using deep learning.

I’m particularly interested in how models become useful software: how data is prepared, how results are evaluated and how people interact with the application.

## Selected projects

### [FindH](https://github.com/Shashiawari/FindH)

A rental verification platform connecting tenants with local agents. Implemented property listings, booking and verification requests, document uploads and administrator review, with separate tenant, agent and admin workflows.

**Stack:** Next.js, React, Node.js, Express, Supabase, PostgreSQL, Socket.IO  
[Visit website](https://findh.vercel.app)

### [Second Brain AI](https://github.com/Shashiawari/Second-Brain)

A knowledge management application for asking questions about uploaded documents and web content. Implemented text ingestion, chunking, hybrid semantic and lexical retrieval, persistent conversations and switching between AI providers.

**Stack:** Python, FastAPI, Next.js, React, Supabase, PostgreSQL, vector embeddings  
[Visit website](https://2ndbrain-ai.vercel.app)

### [Digital Health Twin](https://github.com/Shashiawari/digital-health-twin)

An educational prototype combining tabular machine learning with retrieval-augmented generation. Built model comparison and evaluation workflows, SHAP feature-importance analysis and similar-record retrieval using UCI heart-disease data and synthetic features.

**Stack:** Python, scikit-learn, XGBoost, PyTorch, SHAP, FastAPI, ChromaDB

### [Defungi CNN V2](https://github.com/Shashiawari/Defungi-CNN-V2)

A fungal image classification project with MobileNetV2 transfer learning and fine-tuning. Implemented augmentation, class weighting and validation, plus ONNX export and a JavaScript interface for browser-based inference.

**Stack:** Python, TensorFlow/Keras, MobileNetV2, ONNX, JavaScript

### [Micro Course Converter](https://github.com/Shashiawari/Micro-Course-Converter-TAADS)

An application that turns PDF and Word documents into structured learning material. Includes summaries, slides, questions, English-to-German translation and PowerPoint export.

**Stack:** Python, FastAPI, Next.js, Hugging Face Transformers, Ollama, PyMuPDF
